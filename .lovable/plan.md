

# Industrial Magic — Visual Laboratory

## Concept
A dark, cinematic portfolio site for a visual laboratory working at the intersection of biology, graphic-novel language, and conceptual scientific art. The experience should feel like paging through an experimental art book — not browsing a studio website.

---

## Design System

### Color Palette
- **Background**: Near-black (deep charcoal, not pure #000)
- **Accent tones**: Deep biological blues, arterial reds, muted bone/ivory
- **Text**: Off-white for headlines, muted warm gray for body
- **White used only as punctuation** — never as default background

### Typography
- **Headlines**: Large, editorial, sometimes oversized — assertive and authored
- **Body text**: Small, minimal, precise — secondary to imagery
- **Manifesto text**: Set apart typographically, treated almost like a visual element itself

### Layout Philosophy
- Asymmetric, curated compositions — no clean corporate grids
- Large blocks of imagery with generous negative space
- Intentional tension between dense visual areas and emptiness
- Scroll pacing that feels cinematic, not informational

---

## Pages & Sections

### 1. Homepage
**Opening moment**: A bold hero animation — a single arresting image or visual fragment that materializes on screen (slow reveal, scale shift, or subtle parallax). The studio name "Industrial Magic" appears with deliberate typographic presence. No tagline. No explanation. Just atmosphere.

**Manifesto block**: A short, poetic statement positioned asymmetrically on a dark field. States that the studio does not create diagrams, simulations, or standard visualizations — but visual interpretations of scientific phenomena. Set in restrained, editorial typography.

**Selected work**: 3–4 projects presented as large image plates — not thumbnails in a grid. Each project gets a conceptual title (not descriptive) and minimal supporting text. Layout is deliberately asymmetric — some images bleed edge-to-edge, others float with tension against empty space. Subtle scroll-based reveals as each project enters the viewport.

**Closing line**: A single sentence or phrase at the bottom — an invitation or provocation, not a call-to-action.

### 2. Project Pages (3–4 projects)
Each project page is a **visual essay**, not a case study:
- **Conceptual title** displayed large and editorial
- **Full-bleed imagery** treated like plates in an art publication — the primary content
- **Optional supporting text**: Brief, poetic, interpretive — never procedural. Positioned asymmetrically alongside or between images
- **No bullet points, no process breakdowns, no "the challenge / the solution"**
- Scroll-based reveals give cinematic pacing to the image sequence

**Placeholder project themes** (with conceptual titles):
1. *"The Architecture of Division"* — Cell mitosis interpreted as structural drama
2. *"Invisible Anatomies"* — Molecular structures rendered as graphic-novel panels
3. *"Signal and Noise"* — Neural pathways visualized as abstract topographies
4. *"Deep Time"* — Evolutionary processes as slow visual narratives

### 3. About Page
- Not a biography. A statement of position.
- Who the studio is, said in 2–3 sentences maximum
- What the work is for — interpretation, not explanation
- Dark, minimal layout. Perhaps a single image alongside the text.
- No team grid. No client logos.

### 4. Contact
- Extremely minimal — email address, possibly a single social link
- Presented with the same typographic care as everything else
- No contact form. The restraint is deliberate.

---

## Navigation
- Minimal top navigation: wordmark "Industrial Magic" on one side, page links on the other
- Links styled with subtle interaction (underline reveal or opacity shift)
- Navigation disappears or reduces on scroll to prioritize imagery
- No hamburger menu — the site has few enough pages to show them all

---

## Interactions & Motion
- **Hero**: One bold opening animation — image reveal with scale/opacity shift, name appearing with deliberate timing
- **Scroll reveals**: Images and text blocks fade in with subtle vertical movement as they enter the viewport — cinematic pacing, not decorative
- **Hover states**: Restrained — slight opacity shifts or scale changes on project images
- **Page transitions**: Clean, no flashy effects — the work speaks

---

## Content Approach
- All placeholder images will use dark, atmospheric compositions (using placeholder services or styled gradient blocks that suggest biological/scientific imagery)
- Copy will be poetic and interpretive, never explanatory
- Titles are conceptual provocations, not descriptions
- The site communicates through visual weight and editorial restraint
